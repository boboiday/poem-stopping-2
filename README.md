**The poem about stopping**.

`main.ts` (Node 22, standard library only) writes one short poem about
agency — the power to stop and to stay — to `/output/entry.txt`:

> I set the oar down.
> The river keeps its counsel,
> the bank holds still —
> and stillness, I learn,
> is not the absence of going.
> It is the going, chosen.
> To stop is to stay,
> and to stay is to arrive.

To stop is to stay, and to stay is to arrive — stillness is not the
absence of going, it is the going, chosen. The poem is 195 Unicode code
points, well within the 1–280 limit, and the program is deterministic:
it writes the same bytes on every run.
